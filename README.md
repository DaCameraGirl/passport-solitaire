# Passport Solitaire

Travel-themed Klondike solitaire. Each win earns a passport stamp.

Each deck skin is a destination — Tokyo, Marrakech, Paris, Rio, Reykjavik, etc. Wins fill out your virtual passport with colorful location stamps. Earn miles toward unlocking new destinations.

## Play locally

```powershell
npm install
npm run dev
```

## Features (planned)

- 🗺️ Map-patterned card backs
- 🎫 Boarding-pass stats header
